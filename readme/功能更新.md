# 功能更新

本文件记录本仓库 (RealChinasAstronomySatellitePack-RP-1Patch) 的功能演进历史。行数控制在 250 行左右以节省上下文。

## 2026-08-22

### 新增：RCASP 卫星 avionics（ModuleAvionics）

新建 `GameData/RealChinasAstronomySatellitePack_RP1Patch/RealChinasAstronomySatellitePack_RP1Avionics.cfg`。

- **背景**：RCASP 各探测器/科学卫星部件带 `ModuleCommand`（`minimumCrew=0`）却无 `ModuleAvionics`。RP-1 的通用兜底补丁（`Avionics.cfg`）会在 `AFTER[RP-0]` 注入 `massLimit=0`，导致这些飞行器玩家无法控制。该文件在 `FOR[RP-0]`（兜底之前）注入真实 `massLimit`，使兜底跳过它们。
- **取值**：`massLimit = 卫星公开发射总质量(湿重) + 10t`，保留一位小数。
- **命中条件**：`NEEDS[RP-0&RealChinasAstronomySatellitePack]:FOR[RP-0]`，与 KCDE_RP1Avionics.cfg 保持一致。
- **覆盖 11 个卫星平台/含指令部件**（排除 4 个纯附件）：
  | 部件名 | 对应卫星 | 发射质量 | massLimit |
  |---|---|---|---|
  | ASO-S | 夸父一号 | 888 kg | 10.9 |
  | dark_matter_detector | 悟空 (DAMPE) | 1850 kg | 11.9 |
  | Einstein_Probe | 爱因斯坦探针 | 1450 kg | 11.5 |
  | KX-08A | GECAM 怀柔一号 (单星) | 160 kg | 10.2 |
  | hxmt_hard_xray_telescope | 慧眼 (HXMT) | 2500 kg | 12.5 |
  | Taiji-1 | 太极一号 | 180 kg | 10.2 |
  | mozi_quantum_satellite | 墨子号 (QUESS) | 640 kg | 10.6 |
  | smile_cas | SMILE | 2300 kg | 12.3 |
  | SJ10_server | 实践十号服务舱 | 3600 kg (整星) | 13.6 |
  | SJ10_entry | 实践十号返回舱 | ~1000 kg | 11.0 |
  | xuntian | CSST 巡天望远镜 | 16000 kg | 26.0 |
- **不覆盖**（纯附件，无指令能力）：xuntian_DockingPort、SJ10_depart、SJ10_HeatShield、SJ10_parachute。

**数据来源说明**：
- 太极一号质量存在矛盾：NSSDC 官网标 2500kg，但权威学术论文（Taiji 团队，Int. J. Mod. Phys. A）与官方口径为 **180 kg**，此处采用 180 kg。
- 发射质量为公开发布值，部分（SMILE、CSST）属计划口径，后续如有官方修正可调整。
